\chapter{Supplementary Tables and Map to the Extended Report}
\label{app:suplementares}

This appendix gives the primary metric of every model on every
dataset, the consolidated costs per model and a summary of the
hyperparameter search spaces. Everything else --- secondary metrics,
effect sizes, chosen hyperparameters, distillation ablations and the
process record --- is in the extended technical report and in the
project repository; Table~\ref{tab:app-mapa} says where.

\section{Primary metric per model and dataset}
\label{app:tabelas}

Tables~\ref{tab:app-binaria}, \ref{tab:app-multiclasse}
and~\ref{tab:app-regressao} give the primary metric of each of the 14
models on each of the 18 datasets, on the test hold-out --- one table
per task, because the primary metric differs across tasks: ROC-AUC
for binary classification (higher is better), log-loss for multiclass
and RMSE for regression (lower is better). The RMSE is on the scale in
which the source suite ships each target
(\texttt{california\_\allowbreak housing} has a binarized target, so
its RMSE is the square root of the Brier score;
\texttt{online\_news} has a log-shares target), so no RMSE is
aggregated across datasets. The two cells marked ``---''
(\texttt{helena} $\times$ TabPFN/TabFM) are the study's structural
exclusions: 100 classes, above both foundation models' architectural
limit; the complete state is 250 measured cells out of
$14 \times 18 = 252$.

\section{Search spaces}
\label{app:espacos-busca}

Table~\ref{tab:app-busca} summarizes, for each of the 12 tuned models,
the hyperparameters searched and their ranges, as defined in the
project's configuration file. Optimization uses Optuna with the TPE
sampler and MedianPruner on the internal 3-fold cross-validation, with
\textbf{100 trials} for the GBDTs and \textbf{25 trials} for the
deep-learning models. The two foundation models, TabPFN and TabFM, are
applied zero-shot and have no search space. Conventions:
$[a,\ b]$ is a closed interval sampled uniformly --- integer when the
limits are written without a decimal point, float otherwise; ``(log)''
marks a float sampled on the log scale; braces list a categorical
choice. Parameter names are the literal strings of the configuration
file.

\section{Chosen hyperparameters}
\label{app:hp-escolhidos}

The winning configuration of each tuned model on each dataset ---
exactly what the final refit and the external folds consumed --- is
tabulated per model and dataset in the extended technical report and
recorded in the project repository. The search does not converge to a
single configuration per model: depths and learning rates vary by
orders of magnitude across datasets.
